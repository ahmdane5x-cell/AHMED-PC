# AHMED-PC - تطبيق التحكم بـ Windows من الجوال

تطبيق متكامل للتحكم بجهاز Windows من الجوال عن بعد.

## الميزات 🎯

- ✅ إيقاف وإعادة تشغيل الجهاز
- ✅ فتح البرامج
- ✅ التحكم بالصوت والشاشة
- ✅ التحكم من أي مكان (شبكة محلية + إنترنت)
- ✅ واجهة سهلة وبسيطة

## البنية 🏗️

```
AHMED-PC/
├── backend/          # برنامج Windows (Python)
├── mobile/           # تطبيق الجوال (React Native)
└── docs/            # التوثيق
```

## التقنيات المستخدمة 🛠️

### Backend
- **Python 3.9+**
- **Flask** (خادم ويب)
- **Socket.IO** (اتصال فوري)

### Mobile
- **React Native**
- **Expo** (لتسهيل التطوير)

## البدء السريع ⚡

### للـ Windows (Backend)
```bash
cd backend
pip install -r requirements.txt
python main.py
```

### للجوال (Mobile)
```bash
cd mobile
npm install
expo start
```
